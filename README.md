En este proyecto he realizado un JSON propio de una de mis series favoritas, con tal y repasar el temario.
El repositorio incluye:
  - hxh.json (JSON)
  - index.html (archivo index tematizado para realizar las actividades, con enunciados incluidos para que no te pierdas en el proceso)
  - script.js (archivo en vacío para comenzar la actividad)
Para ejecutar el JSON en local:
  - A ver, sinceramente sólo he probado con Node.js. Pasos:
    1. Descarga Node.js
    2. Una vez instalado, abre el CMD y haz cd hasta la ruta donde se encuentre hxh.json.
    3. Cuando te sitúes en ese directorio, puedes hacer el siguiente comando de Node para ejecutar un servidor local con el puerto que tú elijas:
       - npx http-server --cors -p //númeroDePuerto// (la primera vez suele salir que necesitas instalar alguna extensión, es normal, presionas Y + enter y se instalará)
    4. Posterior a la ejecución del anterior comando, simplemente escribe en la barra de navegación de tu ordenador CUALQUIERA de las IP's que el servidor te menciona al iniciarlo.
       - Una de las funcionales es http://127.0.0.1:3000.
    5. Disfruta de tus ejercicios!
