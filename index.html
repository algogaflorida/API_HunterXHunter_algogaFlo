Asociación de Cazadores · Registro de usuarios de Nen

Examen de Cazador

Desarrolla una página que consulte el archivo hxh_corregido.json y muestre los personajes de Hunter x Hunter.

  1. Selecciona el contenedor principal de tarjetas y establece un límite de 20 personajes por página.
  2. Selecciona los botones de paginación y crea una variable para controlar la página actual. Los botones «ANTERIOR» y «SIGUIENTE» deben cambiar de página.
  3. Prepara un modal que muestre la imagen, el nombre, el estado, el tipo de Nen y la ubicación del personaje. Debe poder abrirse al pulsar una tarjeta y cerrarse con la X.
  4. Crea una función asíncrona para cargar el JSON. Comprueba antes de convertir la respuesta.
  5. Utiliza la función necesario para recorrer los personajes y crea las tarjetas. Cada tarjeta debe mostrar la imagen, el nombre y el tipo de Nen.
  6. Añade un buscador por nombre. Al pulsar «BUSCAR», muestra el personaje cuyo nombre coincida exactamente con el texto escrito. Si no existe, muestra un alert.
  7. Controla la visibilidad de los botones de paginación según la página actual. Al realizar una búsqueda, vuelve a la primera página.

Importante: utiliza únicamente las herramientas y métodos trabajados en el ejercicio anterior. No se deben falta añadir filtros avanzados ni librerías externas.
